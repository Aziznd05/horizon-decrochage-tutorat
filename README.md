# Horizon - Anticiper le décrochage et mesurer l'effet du tutorat

**Étudiant** : Aziz
**Filière** : Expert IA & LLM
**Institut** : Institut Supérieur Horizon

## Objectif
Ce projet vise à nettoyer les données de 5 000 étudiants, à modéliser le risque de décrochage (analyse de survie), à estimer l'effet causal du tutorat (inférence causale) et à fournir un outil d'aide à la décision (dashboard + assistant LLM).
